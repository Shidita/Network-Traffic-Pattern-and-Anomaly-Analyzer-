# Network Traffic Pattern & Anomaly Analyzer

A clean, interactive DAA mini-project using Flask, SQLite and algorithmic traffic analysis.

## Run
```bash
python -m pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000`

## Demo
A synthetic dataset is included in `data/network_traffic.csv`.

## DAA Algorithms
- Merge Sort — O(n log n)
- Binary Search — O(log n)
- Sliding Window analysis — O(n) for a fixed window
- Statistical anomaly scoring using global and local traffic behavior

Use only synthetic or authorized network data.
